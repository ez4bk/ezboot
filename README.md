# ezboot

The package ezboot provides a simple and elegant way to
create and start a distributed service.

### Installation

```bash
go get -u github.com/ez4bk/ezboot
```


### Quickstart

Install the framework tools to create and maintain projects

```bash
go install github.com/ez4bk/ezboot/cmd/ezboot@latest
```

and enter the following in your terminal for getting help

```bash
ezboot --help
```


### Example

Please visit the example in [ezboot-template](https://github.com/ez4bk/ezboot-template).


### Tools

```bash
go install github.com/ez4bk/ezboot/cmd/snowflake@latest
```
